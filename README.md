# Mis gastos

Web app (PWA) para ver mis finanzas personales: gastos, ingresos, análisis, plan de ahorro y objetivos.

Los datos vienen de mi planilla de Google "Mis gastos", que un Google Apps Script completa solo cada 15 minutos con los avisos de Itaú, Santander y Wise de mi Gmail. Esta app no guarda datos en el repositorio: los pide a la planilla con una clave que queda solo en mi dispositivo.
